═══ SMVT ChimeraX 3D Binding Site Scripts ═══

How to use:
1. Open ChimeraX
2. File → Open → select any .cxc file
   OR drag-and-drop .cxc into ChimeraX window
3. Script auto-loads the centroid PDB, renders, saves PNG
4. PNG saved to same folder as .cxc

Compounds:
  HYDROMORPHONE.cxc  →  Hydromorphone
  NAFTAZONE.cxc  →  Naftazone
  PHENOBARBITAL.cxc  →  Phenobarbital
  FUROSEMIDE.cxc  →  Furosemide
  BIOTIN.cxc  →  Biotin
  ESKETAMINE.cxc  →  Esketamine
  GABAPENTIN_ENACARBIL.cxc  →  Gabapentin Enacarbil
  RIBOFLAVIN.cxc  →  Riboflavin

Output: 2400×1800 PNG, transparent background, 4× supersample
